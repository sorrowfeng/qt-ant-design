# Security Policy

## Supported Versions

Security fixes are considered for the latest released version and the current `dev` branch.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a Vulnerability

Please do not open a public issue for a suspected security vulnerability.

Report privately through GitHub's private vulnerability reporting if it is enabled for the repository. If it is not available, contact the repository owner through the profile contact channels and include:

- A short description of the issue.
- A minimal reproduction or affected API.
- Qt version, compiler, operating system, and build type.
- Whether the issue affects consumers at build time, runtime, or packaging time.

We will acknowledge valid reports as soon as possible and coordinate a fix before public disclosure.
