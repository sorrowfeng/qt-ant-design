Compatibility

兼容性与质量

项目同时面向 Qt5 与 Qt6，重点处理控件默认样式、图标渲染、高 DPI、窗口系统和多分辨率显示差异。

质量快照 Qt 版本 高 DPI 质量门禁 Pages 发布

质量快照

Qt5 + Qt6

CMake 自动识别 Qt5 / Qt6，当前重点验证 Qt 5.15.2 与 Qt 6.x。

High DPI

覆盖 1.0、1.25、1.5 缩放比例，减少多分辨率下的尺寸和截图漂移。

Icon Parity

AntIcon 使用统一 SVG 资源和渲染路径，目标是在 Qt5 与 Qt6 下保持同一视觉结果。

47 个 CTest

包含组件行为、视觉 atlas、度量审计、无 QSS 门禁和 example 页面遍历。

Qt 版本

CMake 配置时使用 find_package(QT NAMES Qt6 Qt5 ...) 自动识别 Qt6 或 Qt5。当前重点验证环境包含 Qt 5.15.2 和 Qt 6.x。

  • Qt5 / Qt6 AntIcon 渲染保持同一 SVG 资源路径和视觉结果。
  • 输入框、树、列表、滚动区域、对话框和文件对话框覆盖专项视觉回归。
  • 安装包消费工程通过 find_package(qt-ant-design CONFIG REQUIRED) 验证。

高 DPI 与多分辨率

AntDesign::configureHighDpi() 在 Qt5 下启用逻辑高 DPI 缩放和高 DPI pixmap，并使用 pass-through scale rounding 策略减少 125%、150% 缩放下的尺寸漂移。AntDesign::initialize() 在 QApplication 创建前调用时会自动完成这一步；创建 app 后仍需调用 AntDesign::initialize(&app) 加载资源、字体和主题。

示例程序在主屏幕分辨率和缩放比例之外，还通过自动化测试覆盖 1.0、1.25、1.5 等比例的逻辑截图尺寸。

质量门禁

组件可靠性

公开组件覆盖 API、信号、生命周期、主题切换和渲染烟测。

视觉对齐

组件截图和 Qt5/Qt6 atlas 对比用于发现渲染差异。

无 QSS 示例

示例程序保持零样式表操作，避免绕开控件自身绘制。

真实页面遍历

示例程序会遍历全部页面并对滚动和空白渲染做检查。

Pages 发布

GitHub Pages 使用独立 gh_page 分支承载静态产物，开发分支只保留生成脚本和源文档。项目页目标路径为 www.sorrowfeng.top/qt-ant-design。
